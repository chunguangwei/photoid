# PhotoID Studio / 智能证件照

Prepare portrait files on your device: custom dimensions and KB limits, background replacement, cropping, advisory checks, and original JPEG with JSON report export.

在本机按自定义像素与 KB 要求准备照片，支持换底、裁剪、参考检测及 JPEG 与 JSON 报告导出。

PhotoID Studio is an independent photo-preparation tool. It is not affiliated with a government agency, does not issue documents, and does not guarantee acceptance. Confirm current requirements with the receiving organization.

本应用与政府机构无关，不出具官方证件，不保证照片被接收。请核对接收机构最新要求。

## Next update / 下一版开发准备

A task-aware local photo finder can review a selected folder or file batch with on-device face detection and crop estimates. Manual photo selection stays available. This feature is in development; see [capabilities and limits](photo-finder) and [release preparation](release/next-photo-finder/).

下一版开发新增按任务要求在本机找照片，可从所选目录或多文件中查看人脸检测、原因和裁剪像素估计，保留人工选图。尚未发布，详见[能力与边界](photo-finder)及[发布准备](release/next-photo-finder/)。
