## 定位

围绕报名/申请的照片文件要求，在设备上完成寻找原图、确认要求、分别制作和文件交付。独立工具，无政府关联、不签发证件、不保证任何机构接收或 App Store 审核通过。

## 当前功能

| 页面/能力 | 用户行为 |
|---|---|
| 首页 | 约 1.6 秒品牌组装动效，可立即进入首页；减少动态效果时直接进入，无六秒倒计时 |
| 报名任务 | 名称、备注、要求来源/日期；最多五份输出；原图与可选要求截图保存在本机 |
| 要求提取 | 选择截图，本机 OCR，人工核对像素/KB/JPEG/底色候选并确认短摘录；来源变化须再确认 |
| AI 找照片（开发新增） | 选择常用/自定义尺寸后，从相册批量或本地目录找图；端侧人脸检测、裁剪像素估计、画质参考，网格预览后直接制作；取消示例入口 |
| 人工选图 | 原有 Files / Photos / 拍照入口保留，不以 AI 推荐为前提 |
| 编辑 | MODNet 本机抠图，五色底，缩放/移动裁剪，精修/清晰度默认零，按每份任务要求制作 |
| 文件核对 | 实际 JPEG 尺寸、字节、格式检查；姿态等算法检测仅供参考，不构成机构认证 |
| 总览/交付 | 要求版本、完成状态和实测结果；按明确操作导出 JPEG + 报告或任务 ZIP |
| 其他工具 | 自定义规格、已有文件只读检查、KB 调整、本地相册、中英文、明暗主题、可访问玻璃导航 |
| 更新 | Android GitHub Releases；iOS 仅走 App Store |

## 本机找照片

详细流程、图示、阈值与限制见 [功能文档](photo-finder.md)。目录与明确多文件是可选来源；不做整个相册索引或身份识别。iOS Vision / Android 随包 ML Kit，无需新增模型下载。EmbeddingGemma 2 仅研究，不是本版已接入能力。

至少一份任务要求才能筛选；低像素、多人、姿态未知或未检测到脸均有明确理由，用户仍可人工判断并选择可解码照片。损坏、不支持、超限和未下载项目单独跳过。任务/文件变化会阻止采用旧结果。原图替换须确认并使旧成片失效。

## 平台与隐私

Android API 26+、iOS 15.5+；主要用于 iPhone，iPad 仍需 iPhone 兼容模式验收。图像处理不上传照片，SDK 技术诊断、文件提供方下载、备份和主动分享按 [隐私政策](privacy-policy.md) 披露，不能泛称整个应用零网络。
