# PhotoID v1.0.0

- 全新自定义规格工作台与统一深浅主题，浮动玻璃导航适配高对比度与 iOS 减少透明度设置。
- 支持导出原始 JPEG 与 JSON 检测报告，保留准确字节数与自定义命名。
- 修复 Android 大图人脸定位坐标缩放及 JPEG 回退路径。
- 修复英文规格搜索、KB 无限上限与不可达目标、裁剪重置及快速换底状态。
- 修复自定义规格并发保存、损坏记录读取与相机异步退出问题。
- KB 工具改为后台压缩；改目标时清除旧结果，并可重新选择照片。
- 新增应用内隐私政策入口，准确披露 ML Kit 技术指标。

Android 使用既有正式发布密钥签名。通用 APK 包含多架构，支持原有自动更新链路。
iOS 安装包与 App Store 审核准备分开，GitHub Release 不代表已上架 App Store。

验证：128 项 Flutter 测试通过，Dart 静态分析无问题。尚未完成实际 Android 设备覆盖安装及系统交付流程验收。iOS 最终归档为 1.0.0 (48)，分发导出等待 Xcode 账号/证书配置；尚未上传或提交 App Store。
