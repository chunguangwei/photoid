# 下一版：选尺寸、批量找照片

> **当前开发版 1.2.0（51）**：按用户反馈简化为“选尺寸 → 选一批照片 → 点一张开始制作”，移除面向用户的示例入口。常用 33 个规格和自定义输入直接可用，主流程不再要求建任务；原有记录和高级工具保留。见 [简版交互说明](ux-1.2.0-build51.md)。build50 材料为历史，不能作为本版最终上架素材。

开发分支：`feat/requirements-workflow`，继续原有产品升级；不是新建应用。此目录覆盖上一轮 requirements-workflow 的增量准备，历史拒审/已发版本记录保持不变。

本版提供相册批量/目录候选筛选、按目标尺寸排序和按需查看的判断依据；保留人工选图/拍照、OCR 要求导入、裁切换底压缩、文件核对及 ZIP 交付。
