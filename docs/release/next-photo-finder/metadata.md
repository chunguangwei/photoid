## English (US)

Name: PhotoID Studio

Subtitle: Find, prepare & check photos

Promotional text:
Find photo candidates in a folder you choose. Compare estimated crop resolution with your task requirements, then prepare and check each file locally. Manual selection stays available.

Description:
PhotoID Studio helps you prepare portrait files for application forms, with a task workflow from requirements to final files.

• Find candidates: choose a local folder or multiple photo files. On-device face detection and image measurements help you review single or multiple faces, pose estimates and crop resolution for your task. Search file names and relative paths; you decide which photo to use.
• Keep control: pick a photo manually from Files or Photos, or take a new one. Finding candidates is optional.
• Record requirements: create custom pixel and KB limits, or extract candidates from a selected requirement screenshot. Review every value and confirm a short source excerpt before saving.
• Prepare separate files: use one original for up to five task outputs, adjust crops and backgrounds, and control JPEG file size.
• Check and deliver: inspect actual file dimensions and bytes, review each output, and share prepared files with readable and JSON reports in a ZIP.
• Try the sample task and photo folder without supplying personal photos. Sample variants run through the same local detector; results may vary by device.

Photo analysis and preparation run on your device. There is no account or photo-processing upload. Selected file providers may download files you explicitly select, and bundled third-party SDKs may send technical diagnostics as described in the privacy policy.

Photo finding is a preparation aid, not identity recognition, a compliance certification or an acceptance guarantee. Detection may miss faces or misjudge quality. Folder/file limits apply; downloaded local JPEG, PNG and decodable HEIC files are supported. Verify clothing, expression, dimensions and current requirements with the receiving organization.

PhotoID Studio is independent of government agencies. It does not issue identity documents or guarantee that an organization will accept a photo.

Keywords: portrait,crop,pixels,jpeg,resize,background,offline,requirements,folder,files

What’s New:

• Manual Files, Photos and camera selection remain available.
• Local sample photos demonstrate the real finder; file and task checks prevent adopting stale results.
• Includes the task requirements, screenshot text extraction and file delivery workflow.

描述：
PhotoID Studio 帮助你围绕报名和申请要求，在本机准备人像照片文件。

• 找候选：选择本地文件夹或多选照片，结合端侧人脸检测与图像测量，查看人数、姿态参考及各项任务的裁剪像素估计；支持文件名与相对路径搜索，由你决定采用哪张。
• 自由选图：仍可直接从“文件”、图库或相机选取原图，智能寻找是可选路径。
• 记录要求：自定义像素与 KB 范围，或从所选要求截图提取候选值。逐项核对并确认短摘录后保存。
• 分别制作：同一原图可为任务制作最多五份成片，分别调整裁剪、底色及 JPEG 文件大小。
• 核对交付：实测成片像素和字节，查看总览，打包成片及可读、JSON 报告为 ZIP。
• 示例体验：无需提供私人照片即可体验示例任务和照片组，使用真实本地检测，结果可能因设备而异。

照片分析与制作在设备上完成，无账号、不为处理上传照片。文件提供方可能下载你明确选中的文件；第三方 SDK 的技术诊断行为见隐私政策。

照片寻找仅供制作参考，不识别身份、不构成合规认证或受理保证，可能漏检或误判画质。文件夹数量、文件大小及像素有上限；支持已下载的本地 JPEG、PNG 及可解码 HEIC。请自行核对接收方最新要求及服装、表情等细节。

本应用与政府机构无关，不签发身份证件，不保证任何机构接收照片。
