# Real-device capture plan — not screenshots

Capture only the final assigned build after device acceptance. No fake UI, substituted widget previews, pre-marked successes or institution branding. Use the same public demo available to every user. Preserve original captures alongside composed store images.

| Order | Actual screen | 中文标题 | English caption |
|---|---|---|---|
| 1 | Home with demo and recent task | 从报名要求开始准备照片 | Start with your application requirements |
| 2 | OCR confirmation with original screenshot and multiple candidates | 识别要求，由你逐项确认 | Read requirements, then confirm each value |
| 3 | Confirmed output with short editable excerpt | 要求和来源一起保存 | Keep requirements with their source excerpt |
| 4 | Real separate crops of two demo outputs | 一张原图，分别制作多个版本 | One source, separate photo files |
| 5 | Delivery overview after actual creation | 对照要求，查看实际文件属性 | Compare requirements with measured files |
| 6 | Export in app; Files contents only as supporting review evidence | 照片与可读清单一起交付 | Export photos with a readable checklist |

Video target 60–90 seconds, recording the real app:

- 0–10s: launch directly to Home, open public demo and show fictional-data notice.
- 10–30s: recognize screenshot; show original, candidates and user confirmation, then add one distinct output. Explain all outputs must be prepared or remove the extra example before exporting the original two.
- 30–55s: prepare Main and Profile separately, crop and save each to the task. If processing is sped up, label the speed-up; never imply universal processing duration.
- 55–75s: open overview, read actual dimensions and bytes, show selected background as a setting rather than independently measured conformity.
- 75–90s: export ZIP > Save to Files, unzip and show two JPEGs, per-file reports and checklist. Review notes explain these are file checks, not institutional certification.

Do not claim the video or screenshots exist until original device captures have been saved and visually inspected. If CUA/native device control remains unavailable, physical device acceptance and capture remain pending.
