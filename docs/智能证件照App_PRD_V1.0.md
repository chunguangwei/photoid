## 1. 项目背景与目标

### 1.1 背景
各类考试报名、入学、签证、社保等场景对证件照规格要求碎片化（尺寸、像素、文件大小、底色、比例各不相同），用户频繁遇到"去照相馆说明不清""自拍不合规被系统打回"的痛点。传统照相馆无法覆盖长尾规格，且流程慢、价格高。

### 1.2 产品目标
- 为用户提供"**选规格 → 拍照/上传 → 智能处理 → 合规检测 → 付费保存**"的一站式证件照服务；
- 覆盖 100+ 长尾规格场景（考试、签证、社保、学籍、宠物等）；
- 通过 AI 处理能力（换底色、换正装、精修、发型）形成差异化，摆脱纯工具的低客单价困境。

### 1.3 成功指标（北极星：付费保存成功率）
| 指标 | 目标 |
|---|---|
| 新用户首次成片率（拍摄→合格） | ≥ 70% |
| 上传→付费转化率 | ≥ 25% |
| 客单价 | ≥ ¥6（加购后 ≥ ¥8） |
| 30日留存 | ≥ 15% |
| 合规检测通过率（检测后仍被官方打回） | ≤ 2% |

| 出国人群（美签、韩签、加签、泰签） | 特殊比例（如1:1方签） | 合规承诺（不过可退） |

## 4. 功能需求详述

### 4.1 首页（P0）

**FR-1.1 核心功能宫格（2×2大卡）**
- 拍证件照：跳转规格选择（同"近期热门"全量列表）
- 换底色：入口，支持上传已有证件照更换蓝/白/红/渐变灰/深蓝等6+底色
- 换正装：AI 虚拟换装（男女各 N 套模板：西装、衬衫、校服等）
- 智能精修：美颜类轻修（磨皮、提亮、去瑕疵），默认轻度，避免过度失真导致审核不通过

**FR-1.2 次级功能宫格（5列横向滑动 + 翻页指示器）**
- 换发型：发型模板替换（标注"1×1 px"占位，实际按模板分辨率）
- 检测：对已有照片做合格性检测（格式/尺寸/大小/底色/头部占比）
- 改KB：将已有照片压缩/调整至目标文件大小区间
- 萌宠证照：宠物证件照（差异化功能）
- 自定义：用户自定义宽高像素、比例、DPI

**FR-1.3 运营位**
- 顶部 Banner：品牌标语（"已为2亿用户拍到满意的证件照"）
- 中部横滑 Banner：2个运营位（隐私保护宣传、形象照增值业务）
- 隐私提示条："除了保证合格的证件照，还特别提醒您关注照片隐私——本地处理，自动打码"

**FR-1.4 近期热门规格流（P0）**
- 列表项展示：场景名 + 像素规格（如"一寸 295×413px"）
- 标签体系：
  - "支持合格检测"（绿标）：该规格接入检测规则引擎
  - "签证照不过，随时退"（绿标）：签证类规格的合规承诺
- 点击进入规格详情页
- 右上角"≡"展开全部分类；悬浮"自定义规格"按钮
- 支持按场景搜索（"没有找到需要的内容？戳我按场景搜索"）

### 4.2 规格详情页（P0）

**FR-2.1 顶部信息区**
- 标题：场景名；标签（支持合格检测）
- 三栏参数：冲印尺寸（mm）｜像素大小（px）｜分辨率（DPI，默认300）

**FR-2.2 要求清单区**
- 交付项勾选状态：保存电子照 ✓ / 冲印全国包邮 ✗（按规格配置）
- 背景色选择器：蓝、白、红、浅蓝渐变、灰、深蓝（多选配置，默认蓝）
- 文件大小：固定区间（如"20KB到30KB"）或"可设置大小 / 无要求"
- 文件格式：JPG
- 其他要求：文本展示（如"免冠，照片可看见两耳轮廓及相当于男士喉结处的地方"）

**FR-2.3 拍摄攻略区**
- 正反示例图（✓正确 / ✗错误）
- 提示文案：如"请站在纯色墙面前拍摄""请正对镜头，露出双耳，对齐参考线后拍摄"

**FR-2.4 底部双按钮**
- 上传（相册选图）
- 直接拍摄（调起相机，进入拍摄页）

### 4.3 拍摄页（P0）

**FR-3.1 实时辅助**
- 半透明参考线框 + 头部椭圆虚线框叠加在相机预览上
- 页面内嵌拍摄攻略轮播（可滑动切换示例）

**FR-3.2 拍摄约束**
- 人脸检测：正脸、露出双耳、双眼水平；不符合时给出文字引导
- 光线检测：过暗/过曝提示
- 分辨率：输出不低于目标规格 2 倍的原始图供后端处理

### 4.4 上传处理页（P0）

处理流水线（异步，单张处理时长目标 ≤ 5s）：
1. **人像分割**：AI 抠图（发丝级），输出透明背景人像
2. **背景合成**：按所选底色填充；支持多底色一次生成（加购项）
3. **换装**（可选）：正装模板融合，边缘自然过渡
4. **精修**（可选）：轻度美颜，参数默认保守
5. **裁剪**：按规格比例 + 头部占比规则自动构图（头部占 7/10 或 2/3 等，按规格配置）
6. **导出**：缩放到目标像素、JPEG 压缩至目标 KB 区间（二分压缩算法）、写入 300DPI 元数据

**FR-4.x 交互要求**
- 每一步支持撤销/重调（底色可反复切换预览）
- 提供"原图/效果图"对比滑动条
- 换装、精修标注"AI生成，审核结果以官方为准"风险提示

### 4.5 合格检测（P0）

**FR-5.1 检测项**
| 检测项 | 规则示例 |
|---|---|
| 文件格式 | 必须为 JPG |
| 文件大小 | ∈ 规格配置的 KB 区间 |
| 像素尺寸 | 等于/大于目标像素（按规格规则） |
| 宽高比 | 误差 ≤ 3% |
| 背景色 | 四角采样 + 主色调聚类，判定蓝/白/红 |
| 头部占比 | 人脸关键点检测，头部高度 ∈ [60%, 75%] |
| 头部位置 | 水平居中偏差 ≤ 5%；顶部留白合规 |
| 人脸质量 | 正脸角度、双眼可见、无遮挡、无闭眼、清晰度 |

**FR-5.2 输出**
- 逐项 ✓/✗ 报告；不通过项给出具体修复建议（"文件过大，建议压缩至20–30KB"）
- 一键修复入口（跳转对应处理功能）

### 4.6 订单确认页（P0）

**FR-6.1 页面结构**
- 商品卡片：场景商品名（如"高考报名（大于384×512px）（高清精修版）"）+ 效果图预览（未付费带水印："保存照片后无水印"）
- 赠品展示：赠电子高清照
- 优惠加购区：
  - 展示"86.9%的人的选择"锚点文案
  - 加购项：多种底色 ¥1.99（划线价 ¥9.98）、一寸单张电子照 ¥1.89（划线价 ¥8.99）、二寸单张电子照 ¥1.89
  - 圆形单选，可多选
- 安心保条："电子照尺寸可免费人工修改1次"
- 价格区：主商品 ¥8.99 + 加购合计
- 底部主按钮：保存电子照
- 悬浮客服入口（耳机图标）

**FR-6.2 支付与交付**
- 微信支付/支付宝；支付成功后自动去水印并保存至相册+App相册
- 支持"重命名文件"（如按教育ID命名——适配学校收集场景）

### 4.7 免费拍 Tab（P1）

- 每日/每周限定免费规格或带水印导出，承接广告变现与拉新；具体权益待运营策略确定。

### 4.8 我的（P1）

- 我的订单（待支付/已完成）、我的相册（历史成片，加密存储）、客服中心、隐私设置、注销账号。

## 5. 非功能需求

### 5.1 隐私与合规（红线）
- 证件照属敏感个人信息：采集前弹窗明示用途、存储期限、删除方式
- 遵循《个人信息保护法》《未成年人网络保护条例》：涉及学生学籍照，需监护人授权流程
- 图片传输全程 HTTPS，存储加密；提供"处理完成后N天自动删除"设置
- 隐私宣传点真实可验证：本地/服务端处理逻辑与宣传一致（"本地处理，自动打码"如做不到则不得宣传）
- 应用备案、SDK 合规清单（工信部要求）

### 5.2 性能
- 首页加载 ≤ 1.5s（规格库本地缓存 + 增量更新）
- AI 抠图 ≤ 3s（中端机）、换装 ≤ 5s
- 崩溃率 ≤ 0.1%

### 5.3 兼容性
- Android 8.0+ / iOS 13+；适配刘海屏、平板（P2）

### 5.4 可用性
- 全链路（打开App→成片）≤ 3 分钟；核心路径不超过 4 个页面层级
- 长辈/家长模式：大字版拍摄攻略图

## 9. 风险与开放问题

1. **AI换装审核风险**：换装照片在严格场景（身份证、签证）可能被官方拒绝——需按规格标注"不建议换装"白名单。
2. **规格库准确性**：各地报名参数每年变化（如高考报名KB区间各省不同）——规格库需标注数据来源与更新时间，建立运营更新SOP。
3. **签证"不过退款"承诺**：需法务审核承诺条款边界。
4. **水印策略平衡**：预览水印过重影响转化，过轻易被白嫖——A/B测试确定。
5. 待确认：免费拍权益细节、会员定价、B端学校批量收集的合作模式。
